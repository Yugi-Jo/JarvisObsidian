# 2026-11-07

## Compiling shorts into single videos, hosting them, then wiping

Joel dropped two short-series from `static.ourdream.ai/dreamyshorts` — **Room for One More** (6 parts) and **Five's a Crowd** (5 parts) — with no instruction attached, then asked to compile each into one video, host it, send the link, and delete the local downloads afterwards. Both were done and the files later wiped on his say-so.

Both series were h264, 720x1280 vertical, 24fps. Everything was joined with the concat demuxer, video stream copied losslessly.

- **Room for One More** — all six parts identical in spec, so a straight `-c copy` join worked → 6:00, 116MB, 115693454 bytes.
- **Five's a Crowd** — video identical across parts, but the **audio sample rate switched partway through** (32kHz on parts 1-2, 48kHz on 3-5). The straight join produced a **12:00 container from 8:00 of real video** — the audio track got padded (audio duration 720s vs video 480s, ratio exactly 48000/32000). Passing `-c:a aac -ar 48000` on the concat demuxer does **not** fix it. The fix that worked: normalise each part's audio to 48kHz in its own pass first, then concat-copy the normalised parts. Result 8:00, 130088304 bytes, clean full decode, 11517 frames = exact sum of the parts.

**Hosting route:** both went up as **GitHub release assets** on the `Yugi-Jo/JarvisObsidian` repo, because a normal `git push` refuses anything over 100MB. Each link was verified by an anonymous re-download and MD5 comparison before being handed over. This is now documented in `03 - Projects/Environment & Access.md`.

Both releases were deleted on request afterwards. Worth remembering: after deleting a release, `releases/download/...` can still return a **CDN-cached 200** for a while — re-check with a cache-buster before concluding the file is still live.

Local parts, outputs and verification copies were deleted after each run. Repo left with zero releases and zero tags.

## Dead ends worth remembering

Most free anonymous file hosts reject this VPS's IP:

- **catbox.moe / litterbox.catbox.moe** — `412 Invalid uploader`
- **0x0.st** — uploads disabled site-wide, no ETA
- **x0.at** (0x0 clone) — hands back a URL that 404s straight afterwards
- **pixeldrain.com** — anonymous upload now requires an API key
- **bashupload.com** — DNS doesn't resolve
- **oshi.at** — TLS handshake fails
- **uguu.se** — actually works, but expires in about 3 hours, so no good for "keep it until I say wipe"
- **GitHub release asset** — the reliable, controllable option when a repo is available

The full host matrix and the whole procedure live in the skill **`host-large-video-publicly`**, not here.
